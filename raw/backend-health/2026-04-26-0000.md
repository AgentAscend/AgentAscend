## 4) Likely cause
- User-scoped endpoints are auth-protected; unauthenticated cron probes correctly fail with 401.
- No local backend process was listening on `127.0.0.1:8000` during this run.

## 5) Suggested fix
- Keep health cron probes focused on safe public checks (`/health`, `/openapi.json`, `/marketplace/live`).
- Add an approved read-only JWT for authenticated smoke checks of `/users/{user_id}/access` and `/users/{user_id}/payments`.
- If local health must be checked, ensure backend is already running before cron executes (do not auto-start in this job).

## 6) MVP block assessment
- **Not a hard MVP blocker**: production health and core route presence are good.
- **Potential integration blocker** only if any client still calls user endpoints without Authorization.
