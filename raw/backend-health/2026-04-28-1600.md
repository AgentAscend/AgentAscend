## 4) Likely cause
- 422 responses are expected validation failures from intentionally minimal probe payloads; routes are alive.
- 401 responses are expected because auth credentials were intentionally not supplied.
- No evidence of backend outage from tested remote endpoints.

## 5) Suggested fix
- No backend code fix required from this check.
- For deeper functional verification, run credentialed integration tests with:
  - valid auth token for `/users/{user_id}/access` and `/users/{user_id}/payments`
  - valid payment test vector (test user + test tx signature) for `/payments/verify`
